# 城市规则与口径

四套规则都在 `city_rules.py`，由 `DesignMetrics.calculate_metrics` 按城市分发到 `CityRules`。
本文件记录各城市的口径差异，供判断「这个项目该用哪套规则」和核对结果时使用。
改规则后必须重跑 `scripts/smoke_test.py`（四城市快照回归，容差 0.01）。

## 通用部分（MetricsHelper）

- 基础面积：`build_basic_area_metrics` → `S_计容面积`(jr)、`销售面积`(sale)、`物理面积`(physical)、`赠送面积`(free)
- 户数：`build_household_metrics` → 总户数、保障房户数、商品房户数
- 停车：`build_parking_metrics` → 地库面积、人防地下室面积、非人防地下室面积、地下机动车数量、
  人防车位数（= 人防面积 ÷ 40）、非人防车位数、地面停车、机动车总数
- 场地：`build_site_metrics` → 用地面积、绿地面积、配套基底面积、商业基底面积、
  住宅基底面积（`floor=1f` 的物理面积）、建筑基底面积、建筑密度、绿地率
- 地下：`build_underground_metrics` → 地库面积、人防地下室面积、地下机动车数量、人防车位数、非人防地下室面积

## 上海（sh）

```
计容面积       = S_计容面积 − 不计容配套面积
配套总面积     = 配套楼栋计容面积 − 不计容配套面积
奖励后计容面积 = 不奖励楼栋计容 + 奖励楼栋计容 × 奖励系数 − 不计容配套面积
奖励面积       = 奖励后计容面积 − 奖励前计容面积
地上总建筑面积 = 奖励后计容面积 + 屋顶机房 + 保障房不计容半阳台 + 不计容配套面积
住宅总建筑面积 = 奖励后计容面积 − 配套总面积 + 屋顶机房 + 保障房不计容半阳台
地库面积       = 地库主体 + 电缆夹层面积
容积率         = 计容面积 / 用地面积
总建筑面积     = 地上总建筑面积 + 地库面积
```

特征指标：`S_建筑工程面积`、`S_计一半面积`（计容系数 = 0.5 的面积）、套内面积、
联排/洋房计容面积拆分、联排奖励面积、洋房屋顶机房面积、保障房不计容半阳台、保障房屋顶机房、
地上电梯厅/楼梯间/连廊/首层大堂、地库大堂、地下储藏间、门卫。

上海用 `楼型` 字段区分 `LP`（联排）、`YF`（洋房）、`BZF`（保障房）、`PT`、`DK`。

## 长沙（cs）

```
不计容住宅面积 = 架空面积 + 屋顶机房面积 + 地下楼梯间面积
配套总面积     = 计容配套面积 + 不计容配套面积
计容总面积     = 计容住宅面积 + 计容配套面积 + 商业面积
地上建筑面积   = 计容住宅 + 不计容住宅 + 商业 + 计容配套 + 不计容配套 + 骑楼面积
总建筑面积     = 地上建筑面积 + 地库面积
容积率         = 计容总面积 / 用地面积
建筑密度       = (住宅基底 + 配套基底 + 商业基底) / 用地面积
```

特征指标：骑楼面积、绿地率、住宅物理面积、赠送面积，基底面积按住宅/配套/商业分列。

## 合肥（hf）

```
住宅计容面积     =（地上住宅面积 − 保障房面积）× 0.97 − 架空面积 × 0.03 + 保障房面积
住宅装配式奖励面积 =（地上住宅面积 − 保障房面积 + 架空面积）× 0.03
计容总面积       = 住宅计容面积 + 计容配套面积 + 商业面积
地上建筑面积     = 地上住宅面积 + 配套总面积 + 商业面积 + 架空面积
容积率           = 计容总面积 / 用地面积
```

**0.97 与 0.03 是硬编码在规则里的政策系数**（空计算容折减、装配式奖励）。
合肥政策调整时这两处要改代码，不能靠参数。

保障房面积按 `楼型 = BZF` 从面积线取。

## 贵阳（gy）

```
计容面积       = S_计容面积（不再扣配套）
地上总建筑面积 = 计容面积 + 架空层面积
住宅总建筑面积 = 地上总建筑面积 − 商办面积
地库面积       = 地下停车场面积 + 人防地下室面积
容积率         = 计容面积 / 用地面积
建筑基底面积   = floor=1f 的物理面积
总建筑面积     = 地上总建筑面积 + 地库面积
```

特征指标：商办面积（`系数key = 商办`）、架空层面积、非人防地下室面积。
贵阳的用地面积口径来自 `补充信息.xlsx` 的 `用地面积`，另可提供 `可计容用地面积`。

## 参数

| 参数 | 界面默认 | 作用 |
| --- | --- | --- |
| 容积率限值 ratio | 1.2 | 只用于算 `差值 = 用地面积 × ratio − 计容面积`，不参与其他指标 |
| 奖励系数 bonus_factor | 1.03（区间 1.0—1.2） | 奖励楼栋计容面积 ÷ 该系数 |
| 自定义奖励楼栋 | 空 | 给定时重算底表，覆盖 `楼栋属性.xlsx` 里的 `是否奖励楼栋` |
| 自定义配套楼栋 | 空 | 给定时重算配套楼栋集合 |

## 试算时的两个不直观之处

1. **`奖励后计容面积` 不随奖励系数变**。上海规则里奖励楼栋的计容面积在建底表时已
   `÷ 奖励系数`，计算时又 `× 奖励系数` 还原，两者抵消。要观察奖励系数或奖励楼栋的影响，
   应看 **`计容面积`**（= S_计容面积 − 不计容配套，随系数变化）和 **`奖励面积`**。
   实测示例（上海样例数据，仅改奖励楼栋名单、系数固定 1.03）：

   | 奖励楼栋 | 计容面积 | 奖励面积 |
   | --- | --- | --- |
   | 默认 9 栋 | 88,219.61 | 1,303.09 |
   | 仅 1 号楼 | 89,496.21 | 26.49 |
   | 1—10 号楼 | 89,231.40 | 291.32 |

2. **奖励系数为 1.0 时，改奖励楼栋名单对计容面积没有影响**（除以 1 等于不折减）。
   做试算对比时先确认系数不是 1.0，否则会得到「改了没反应」的错觉。

## 输出

`metrics_output` 把指标字典与 `补充信息.xlsx` 合并，**过滤掉数值为 0 的项**，按数值降序排列。
因此「算出来是 0」和「没有这一项」在指标表里无法区分；需要区分时看 `--outdir` 导出的楼栋面积表。

各城市输出的指标字段清单在 `design_metrics.DesignMetrics.OUTPUT_FIELD_CONFIG`，
未列入该清单的指标即使算出来也不会进输出表。
