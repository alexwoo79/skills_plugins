# 可研阶段用地测算与楼型组合建议

前置：输入为本地文件绝对路径（`.json` 或 `.xlsx`）；计算一律通过 `scripts/keyan.py` 完成，
不在对话里手算指标、不臆造输入条件。口径源为本工程 `keyan_calculation.py`（可研阶段方案测试工具 v4.0）。

## 核心铁律

1. **数值只能来自脚本返回**。禁止凭经验估算计容面积、户均面积、楼栋数、密度等任何指标。
2. **缺必填条件不等于可以代填**。脚本会拒绝测算并列出缺项，此时把缺项清单交给用户去要数据；不要用假定值绕过。
3. **自动补值必须显式披露**。脚本对未提供的「重要」条件按 0 计，这些项会出现在 `自动补值项` 与报告第二章中，必须在答复里提示复核。
4. **一次运行只产出一套口径**。报告、xlsx 报表、csv 指标必须来自同一次 `report` 运行，避免出现"报告对应哪个版本数据"说不清的情况。
5. **结论必须带数据等级**。L1 估算级不可对外承诺，L2 方案级不可直接报批，L3 报批级才可与报批指标表逐项对账。
6. 输出简体中文，数值加千分位；用户未指定路径时，产物写入用户给定目录，不要散落到工程根目录。

## 快速命令

```bash
SKILL=~/.codex/skills/keyan-calculation          # 安装后位置；未安装时用本工程 keyan-calculation/ 目录
$PY $SKILL/scripts/keyan.py template --out 输入模板.xlsx
$PY $SKILL/scripts/keyan.py check  --input 项目.json
$PY $SKILL/scripts/keyan.py calc   --input 项目.json  [--outdir 目录]
$PY $SKILL/scripts/keyan.py report --input 项目.json  --outdir 目录
```

- `template`：生成 xlsx 输入模板（用地条件 / 户型配比 / 楼型候选 / 外部条件 / 寻优参数 五张表）。
  用户手上没有数据文件时，先给模板让他填，比来回问答快。
- `check`：只做完整度体检 + 自洽性校验，输出完备度得分、数据等级、待补充清单、校验问题。
  **拿不准输入够不够时先跑这个**。
- `calc`：完整测算 + 楼型组合枚举比选，stdout 输出 JSON（关键指标、楼型参数、推荐与备选方案）。
- `report`：一次产出 xlsx 数据报表（8 张表）、markdown 测算报告、csv 关键指标。

## 标准工作流

1. 判断用户手上有什么：有数据文件 → 直接进第 3 步；没有 → 先 `template` 给模板。
2. 用户给了零散条件（用地面积、容积率、限高……）但没给文件时，由**用户明确给出的数值**组装 json 落盘，
   对用户没说的条件留空并在 `check` 后一次性问齐，不要逐个字段来回确认，也不要替他编。
3. `check`：把 `待补充` 与 `校验问题` 用表格反馈给用户，说明补齐哪些项能把等级从 L1 提到 L2/L3。
4. 条件够跑（必填齐全）→ `report` 出全套产物；条件不够 → 停在 `check`，给补充清单，等用户补数据。
5. 交付时说明：数据等级、推荐方案（楼型×楼栋数）、面积利用率、总建筑密度与上限的余量、配比偏差、
   自动补值项、以及必须人工复核的专项（日照／退线／消防／地下车库）。

## 模型与评分口径

模型为「指标倒推 + 楼型组合枚举比选」：由用地条件倒推总计容面积与住宅计容面积，按配建与奖励口径还原
可建面积，由限高链推出极限层数，在楼型候选 × 楼栋数空间内枚举，按四项加权打分：

| 维度 | 权重 | 含义 |
| --- | --- | --- |
| 面积利用率 | 40% | 组合建筑面积 ÷ 商品房可建面积，越接近 100% 越好 |
| 配比符合度 | 25% | 1 − 计算套数比与输入套数比的偏差（总变差距离） |
| 户均达成度 | 20% | 1 − 计算户均面积与目标户均面积的相对偏差 |
| 集约度 | 15% | 楼栋数越少越好（管理成本低） |

约束：组合面积 ≤ 商品房面积 且 ≥ 商品房面积 ×(1−面积下浮下限)；总基底面积 ≤ 用地面积 × 建筑密度。
默认面积下浮下限 3%、配比偏差上限 5%，均在 `寻优参数` 中可调。权重与阈值属于可调参数，
用户有自己的比选习惯时按用户口径改，并在报告中注明。

详细的输入字段说明见 [references/输入格式.md](references/输入格式.md)，
完整公式链、自洽性校验规则、与原程序的差异见 [references/测算口径与公式.md](references/测算口径与公式.md)。

## 常见情况处理

- **脚本报"必填条件缺失"**：不要改脚本绕过。逐条把缺项和来源方列给用户，并说明缺哪一项会失掉哪个指标。
- **`提示` 里出现"已放宽配比约束"**：说明现有楼型候选凑不出目标配比。要向用户点明这是楼型候选的问题，
  建议补充不同户型组合的楼型或调整层数，而不是把放宽后的结果当结论。
- **没有可行组合**：说明在面积下浮下限与密度约束下无解，给出三条处置：补充更接近极限层数的楼型候选、
  调整层数、或放宽面积下浮下限（并说明放宽的代价是剩余面积变大）。
- **`校验问题` 出现 C2（容积率—密度—限高矛盾）**：这是输入条件自身矛盾，必须先让用户复核，
  不要用某一种楼型硬凑出结果。
- **需要货值比选**：本模型只出物理指标，须先补 `成本售价假设` 才能扩展到货值维度。
