# 输入格式

输入为 `.json` 或 `.xlsx`。xlsx 用 `scripts/keyan.py template --out 模板.xlsx` 生成，
含五张表：`用地条件`（key-value）、`户型配比`、`楼型候选`、`外部条件`（key-value）、`寻优参数`（key-value）。

## 一、用地条件（必填项缺失即拒绝测算）

| 字段 | 单位 | 级别 | 说明 |
| --- | --- | --- | --- |
| 项目名称 | — | 可选 | 报表与报告标题，缺省为「未命名项目」 |
| 用地面积 | m² | 必填 | 挂牌文件或规划设计条件通知书 |
| 容积率 | — | 必填 | 区间时取上限验算 |
| 限高 | m | 必填 | 规划条件、航空与地方限高综合确定 |
| 建筑密度 | 小数 | 必填 | 输入 0.28 而非 28 |
| 层高 | m | 必填 | 住宅标准层高 |
| 商业面积 | m² | 重要 | 缺失按 0 计，会使住宅计容面积偏大 |
| 公共配套面积 | m² | 重要 | 同上 |
| 物业用房面积 | m² | 重要 | 同上 |
| 配电房和开闭站面积 | m² | 重要 | 同上 |
| 非住宅基底面积 | m² | 重要 | 缺失按 0 计会低估建筑密度 |
| 室内外高差 | m | 重要 | 缺失按 0 计会使极限层数偏大 |
| 女儿墙 | m | 重要 | 缺失按 0 计会使极限层数偏大 |

## 二、视情启用模块

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| 架空层启用 | 有 / 无 | 无则架空层高度与架空率强制为 0 |
| 架空层高度 | m | 启用时必填，参与极限层数计算 |
| 架空率 | 小数 | 启用时必填，决定架空层面积与架空层奖励面积 |
| 保障房启用 | 有 / 无 | 无则全部住宅计容面积计入商品房 |
| 保障房模式 | 面积比例 / 输入面积 | 决定保障房计容面积的取法 |
| 保障房面积比例 | 小数 | 按「面积比例」模式时必填，乘总计容面积 |
| 保障房输入面积 | m² | 按「输入面积」模式时必填 |
| 保障房户均面积 | m²/户 | 决定保障房户数 |
| 保障房标准层户数 | 户 | 决定保障房基底面积（标准层户数×户均面积+20） |
| 商品房奖励系数 | 小数 | 乘商品房计容面积 |
| 保障房奖励系数 | 小数 | 乘保障房计容面积 |
| 架空层奖励系数 | 小数 | 乘架空层面积 |

启用保障房但对应的面积比例／输入面积为空时，脚本会直接报错，不按 0 静默处理。

## 三、户型配比

两种口径，用 `配比口径` 指定（默认套数比）：

- `套数比`：`[{面积段: 90, 套数比: 0.25}, ...]`，合计按 1.0 归一化。
- `面积比`：`[{面积段: 90, 面积比: 0.25}, ...]`，脚本按原程序口径换算套数比：
  `户型段面积 = 面积比 × 商品房面积`，`户型套数 = 户型段面积 ÷ 面积段`，再归一化为套数比。

合计与 1.0 偏差超过 2% 时会在自洽性校验中提示（C6），但计算仍按归一化结果进行。

## 四、楼型候选

```json
[
  {"楼型": "T8", "户型组合": "80x2+90x4+120x2"},
  {"楼型": "T4", "户型组合": "125x2+143x2", "层数": 18},
  {"楼型": "T2", "户型组合": "143x2", "楼栋数下限": 0, "楼栋数上限": 6}
]
```

| 字段 | 说明 |
| --- | --- |
| 楼型 | T1—T8，代表单元每层户数；超出范围直接报错 |
| 户型组合 | `面积段x数量` 用 `+` 连接；数量合计应与楼型每层户数一致，不一致会出告警 |
| 层数 | 可空，默认取极限层数向下取整；超过极限层数会被截断并告警 |
| 楼栋数 | 给定则锁定该值（上下限同值） |
| 楼栋数下限 / 上限 | 枚举范围，默认 0 至 `商品房面积 ÷ (标准层面积 × 层数)` 向下取整 |

同一个楼型代码可以出现多次（不同户型组合），脚本内部用 `楼型-户型组合` 作为唯一标识。

## 五、外部条件

`规划细则版本`、`日照要求`、`退线要求`、`车位配比`、`得房率上限`、`赠送面积口径`、
`地下室指标`、`装配式要求`、`成本售价假设` 九项。这九项不参与物理指标计算，
只用于完整度评分、数据等级判定与报告提示。九项齐备才会判为 L3 报批级。

## 六、寻优参数

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| 面积下浮下限 | 0.03 | 组合面积不得低于可建面积的 97% |
| 配比偏差上限 | 0.05 | 配比偏差超过该值即放宽并提示 |
| 密度利用下限 | 0.80 | 保留参数，用于识别密度利用过低 |
| 方案数上限 | 5 | 输出方案条数 |
| 权重 | 见 SKILL.md | 面积利用率／配比符合度／户均达成度／集约度 |
