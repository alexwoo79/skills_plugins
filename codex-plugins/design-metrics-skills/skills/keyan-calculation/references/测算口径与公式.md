# 测算口径、公式链与校验规则

口径源：本工程 `keyan_calculation.py`（可研阶段方案测试工具 v4.0）。本文档记录脚本实现的公式、
自洽性校验规则，以及与原程序存在的三处差异，供口径对齐与向用户解释时使用。

## 一、指标链

| 环节 | 公式 |
| --- | --- |
| 总计容面积 | 用地面积 × 容积率 |
| 住宅计容面积 | 总计容面积 − 商业 − 公共配套 − 物业用房 − 配电房和开闭站 |
| 极限层数 | (限高 − 架空层高度 − 室内外高差 − 女儿墙) ÷ 层高，展示保留 2 位，取用向下取整 |
| 住宅基底面积上限 | 用地面积 × 建筑密度 − 非住宅基底面积 |
| 架空层面积 | 住宅基底面积上限 × 架空率（未启用架空层时为 0） |
| 保障房计容面积 | 按比例：总计容面积 × 保障房面积比例；按面积：保障房输入面积 |
| 商品房计容面积 | 住宅计容面积 − 保障房计容面积 |
| 商品房奖励面积 | 商品房计容面积 × 商品房奖励系数 |
| 保障房奖励面积 | 保障房计容面积 × 保障房奖励系数 |
| 架空层奖励面积 | 架空层面积 × 架空层奖励系数 |
| 商品房面积 | 商品房计容面积 + 商品房奖励面积 + 架空层奖励面积 |
| 保障房面积 | 保障房计容面积 + 保障房奖励面积 |
| 保障房基底面积 | 保障房标准层户数 × 保障房户均面积 + 20 |
| 商品房户均面积 | Σ(套数比 × 面积段) |
| 商品房平均户数 | 商品房面积 ÷ 商品房户均面积 |
| 楼型标准层面积 | Σ(户型面积段 × 该户型数量) |
| 楼型户均面积 | 标准层面积 ÷ 每层户数 |
| 单栋户数 | 每层户数 × 层数 |
| 楼型最大楼栋数 | 商品房面积 ÷ (标准层面积 × 层数) |
| 组合建筑面积 | Σ(标准层面积 × 层数 × 楼栋数) |
| 组合户数 | Σ(单栋户数 × 楼栋数) |
| 总基底面积 | 商品基底 + 保障房基底 + 非住宅基底 |
| 总建筑密度 | 总基底面积 ÷ 用地面积 |
| 商品房总建筑面积 | 商品房计容面积 + 商品房奖励面积 + 商品房屋顶机房面积 + 商品房阳台面积 |

屋顶机房与阳台在本版按 0 计（原程序注释说明户配表面积已含机房与阳台）。

## 二、自洽性校验（脚本自动判定）

| 编号 | 校验事项 | 触发条件 | 级别 |
| --- | --- | --- | --- |
| C1 | 极限层数 | 极限层数 < 3 层 | 高 |
| C2 | 容积率—建筑密度—限高自洽 | 用地面积×建筑密度×极限层数取整 < 总计容面积 | 高 |
| C3 | 住宅计容面积 | ≤ 0 | 高 |
| C4 | 配套类面积占比 | 商业+公配+物业+配电房 > 总计容面积 15% | 中 |
| C5 | 保障房计容面积 | ≥ 住宅计容面积 | 高 |
| C5b | 保障房参数 | 标准层户数或户均面积为 0 | 中 |
| C6 | 配比合计 | 与 1.0 偏差 > 0.02 | 中 |
| C7 | 楼型户型与配比一致性 | 楼型中出现配比表以外的面积段 | 中 |
| C8 | 楼型可行性 | 某楼型最大楼栋数 < 1 | 中 |

C2 是最有价值的一条：它把「容积率、建筑密度、限高」三个来自不同文件的数字放在一起验算，
三者矛盾时项目其实无法按给定条件落地，必须先复核输入而不是继续调楼型。

## 三、数据等级判定

| 等级 | 判定 | 可用范围 |
| --- | --- | --- |
| L0 不可测算 | 必填项缺失 | 只能补条件 |
| L1 估算级 | 必填齐全，但重要项缺失或外部条件 ≤2 项 | 方案早期总量判断与楼型方向筛选 |
| L2 方案级 | 重要项齐全，外部条件 3—8 项 | 方案阶段比选与内部对账 |
| L3 报批级 | 九项外部条件齐备 | 可与报批指标表逐项对账 |

完备度得分按权重计算：必填 3、重要 2、视情 1、外部 1、可选 0.5。

## 四、与原程序的三处差异（须向用户说明）

1. **保障房户数**：原程序 `保障房户数 = 保障房面积 ÷ (标准层户数 × 户均面积)`，量纲实为「层数」。
   本脚本按 `保障房面积 ÷ 户均面积` 计户数，并另设「保障房折算层数」保留原值。
   若沿用原程序口径对外报数，需先确认对方接受哪一种。
2. **商品房基底面积**：原程序使用说明写 `(n × 户均面积 + 20) × 楼栋数`，实际代码为 `标准层面积 × 楼栋数`。
   本脚本与代码一致；`+20` 只出现在「保障房基底面积」与原程序的最大楼栋数预估中。
3. **阳台与屋顶机房**：原程序新版本已按 0 处理（注释：户配表面积已含机房与阳台）。本脚本一致。
   若地方细则要求单独计容，应在奖励系数中体现。

这三条属于口径漂移，报告中单列一章说明，避免出现同一次测算两处口径不一致。

## 五、模型边界

本模型只做物理指标，不含：日照与间距校核、退线与消防、地下车库与车位、得房率、
赠送面积合法性判定、货值与成本、装配式与绿色建筑增量。上述内容需叠加专项校核后才可作为报批依据。
