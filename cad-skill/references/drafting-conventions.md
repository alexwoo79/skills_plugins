# 建筑制图约定与流程

## 单位与尺度

- 图纸单位统一 mm，且在回复里写清楚（“单位 mm”）。
- 常用参数：外墙 240、内墙 200、入户门 1000、卧室门 900、卫生间门 800、常用轴距 3600。
- 文字高度按 mm 图纸给：房间名 250–350，标注字高 200–250，轴号 300–400。默认 2.5 等于看不见。
- 坐标写法：`[x, y]`，左下角为原点，y 向上为正。

## 图层

| 图层 | 内容 |
| --- | --- |
| A-WALL | 墙体（含洞口封边线） |
| A-DOOR | 门扇、开启弧 |
| A-WINDOW | 窗线（三线示意） |
| A-GRID | 轴线、轴号圆圈与文字 |
| A-DIM | 尺寸标注 |
| A-TEXT | 房间名、说明文字 |
| A-FURN | 家具示意 |
| A-HATCH | 填充 |

每个绘图调用都带 `layer`。不要把所有内容画在 `0` 层。

## 分步顺序（每步画完请用户检查）

| 步骤 | 画什么 | 检查点 |
| --- | --- | --- |
| 1 | 图层就绪（靠绘图调用的 `layer` 参数自动建层） | `list_layers` 能看到 8 个层 |
| 2 | 轴网：轴线 + 轴号圆圈 + 轴号文字 | 轴距与轴号与方案一致 |
| 3 | 外墙：闭合多段线表达墙厚 | 外轮廓闭合、无缺口、墙厚正确 |
| 4 | 内墙：同上 | 房间分隔与方案一致 |
| 5 | 门窗：洞口封边 + 门扇弧 / 窗三线 | 门窗宽度、位置、开启方向 |
| 6 | 家具示意：矩形/多段线 + 文字 | 不压墙线、尺度合理 |
| 7 | 文字与尺寸：房间名、控制尺寸标注 | 位置不压建筑线、数值与确认参数一致 |
| 8 | `save_drawing` 存 DWG/DXF | 绝对路径、文件名明确 |

墙线是地基：坐标错了，门窗、家具、标注会跟着全错。宁可多停一步让用户确认。

## 构件画法细则

**墙体**：每段墙用一个闭合多段线表示矩形截面（沿墙长的两条外边 + 两端的墙厚端线），端部按转角延伸 半墙厚 近似接角。转角处如出现缺口，用 `draw_hatch`（SOLID）或补角多段线填实。

**门**：先在洞口两侧各画一条跨墙厚的封边线（A-WALL），再画门扇线（从合页点沿开启方向，长度 = 门宽）与 90° 开启弧（`draw_arc`，圆心 = 合页点，半径 = 门宽，逆时针）到 A-DOOR。

**窗**：洞口两侧封边线（A-WALL）+ 洞口内外两条墙面线 + 中间窗线（A-WINDOW），即三线示意。

**轴网**：轴线用 `draw_line` 画到图外一圈（A-GRID），端部 `draw_circle` 画轴号圆圈，`draw_text` 写轴号（横向 1/2/3…，纵向 A/B/C…）。

**家具**：矩形 / 多段线示意即可，文字标名称（A-FURN）。不要把家具做成精细图块。

**尺寸**：`add_dimension` 成对给控制尺寸——总开间/总进深、各轴线间距。放在图形外侧，避免与墙线、文字重叠。

**用脚本生成而不是手算**：轴网、分段尺寸和直跑楼梯都写在 `plan.json` 的 `axis` / `dims` /
`stairs` 里，由 `scripts/plan_render.py` 一次出 calls、`.scr`、DXF 和 SVG 预览；
字段与示例见 `references/plan-render.md`。DXF 后端加 `--blocks` 可以把门窗换成
单开/推拉图块；直连落图仍按基础图元。

## 给用户的 Prompt 模板（可直接复用）

方案阶段（不调 CAD）：

```text
【项目类型】两居室住宅
【建筑尺寸】12000 × 8000mm
【单位】mm
【功能】客厅、餐厅、厨房、主卧、次卧、卫生间、玄关
【空间关系】客厅餐厅相连；厨房近餐厅；卧室偏北；卫生间近卧室
【墙体】外墙 240，内墙 200
【门】入户 1000，卧室门 900，卫生间门 800
【窗】主卧 1800，次卧 1500，客厅 2400
【图层】A-WALL / A-DOOR / A-WINDOW / A-DIM / A-TEXT / A-FURN / A-GRID
请先只输出布局方案：1) 各房间尺寸 2) 房间位置（坐标或轴网）3) 房间关系 4) 主要墙体控制点。
暂时不要调用 CAD。我确认后再开始绘图。
```

分步绘图指令：

```text
按已确认方案，先只画外墙与内墙（闭合多段线表达墙厚），图层 A-WALL。
不要门窗、家具、标注。画完截图给我看，等我确认。
```

修改指令：

```text
客厅南北方向再大 600mm。请给出新的墙线控制点，重画受影响的墙段与相邻房间边界，
并更新相关尺寸标注；家具先删除后按新位置重画。
```

首轮如果用户只给一句“帮我画个住宅”，先把上面的条件表问齐，或按合理默认值列出来请其确认，不要直接开画。

## 常见错误

| 踩坑 | 后果 | 对策 |
| --- | --- | --- |
| 一句“画个住宅”直接调 CAD | 设计、尺寸、几何、调用错误叠加 | 先出方案并确认 |
| 所有图元画在 0 层 | 无法过滤、无法出图 | 每个调用都传 `layer` |
| 文字/标注用默认字高 | 在 mm 图纸里看不见 | 显式给 200–350 |
| 一次把墙门窗家具全画完 | 错一处要全删 | 分步 + 每步截图确认 |
| 假设能“挪墙并联动” | 图面自相矛盾 | 按新参数重画局部，再更新标注 |
| 门窗只剩洞口没有封边 | 墙线断开、不像墙 | 洞口两侧补跨墙厚封边线 |

## 项目级 AGENTS.md 模板

长期做建筑 CAD 时，把这份规范放到项目根目录：

```markdown
# 建筑 CAD 绘图规范

## 单位
所有尺寸使用毫米。

## 图层
A-WALL / A-DOOR / A-WINDOW / A-DIM / A-TEXT / A-FURN / A-GRID / A-HATCH

## 原则
1. 先确认布局参数，再调用 CAD。
2. 墙、门、窗用基础图元组合表达，不假设存在专业墙对象。
3. 分步绘制：图层 → 轴网 → 外墙 → 内墙 → 门窗 → 家具 → 文字 → 尺寸 → 保存，每步等待检查。
4. 修改优先重画局部，而不是假设能复杂联动修改。
5. 避免重复线与明显重合对象。
6. 尺寸与文字不压住主要建筑线。
7. 完成后保存 DWG/DXF（绝对路径）。
8. 未经确认不擅自改动设计意图。
```

## 学习路线

| 级别 | 练什么 | 目标 |
| --- | --- | --- |
| Level 1 | 直线、矩形、圆、多段线 | 确认链路能控制 CAD |
| Level 2 | 房间轮廓、墙厚示意、门窗示意、文字尺寸 | 简单平面 |
| Level 3 | 轴网、功能分区、家具示意、图层 | 完整小户型平面 |
| Level 4 | 按新尺寸重画局部、改门窗、改开间 | 理解“改意图 → 改几何” |
| Level 5 | AGENTS.md + Prompt 模板 + 构件画法约定 | 形成个人工作流 |

第一个练习项目建议是 100㎡ 左右的两室一厅平面示意，不要一上来就做大型公建或全套施工图。
